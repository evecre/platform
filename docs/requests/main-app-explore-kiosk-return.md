# 本体への依頼：公開ページ（/explore）から外部サイトの Top へ戻れるようにする（展示モードを含む）

> 送り先：イベクリ本体を開発している Claude Code
> 作成：2026-11-11（外部サイト側。本体は `243cbcb` の `server.js` の `_publicSiteUrl()`・`GET /api/config` を読んで確認した）
> 位置づけ：本体の指示書「公開ページ（一覧・告知モーダル・ナレッジページ）と、いいね・コメント」（`docs/main-app-explore-instructions05.md`）への**追加**。その Phase 3（画面）と一緒に入れてよい

---

## 0. 背景

公開イベントの一覧・告知・ナレッジ（ユーザーは「みんなの記録」と呼んでいる）を、外部サイトから本体の `/explore` に移す。外部サイトには Top（イベクリの説明）とチャットボットが残り、「みんなの記録を見る」ボタンで `/explore` に移動する。

困ること：

1. `/explore` から外部サイトの Top（イベクリの説明）に戻る道が無い
2. 外部サイトは**展示会**で使う（`?kiosk=1`。55インチモニター・タッチ）。外部サイトでは「Top 以外で3分操作が無ければ Top に戻る」ようにしているが、`/explore` に移ると、その仕組みが効かず、来場者が触ったページのまま止まる

## 1. 作るもの

### 1-1. `/explore` から外部サイトの Top へのリンク（いつも）

- 公開ページのヘッダー（指示書 §5-6）に、外部サイトの Top へのリンクを足す。文言の例：「イベクリについて」
- 行き先は **`GET /api/config` の `publicSiteUrl`**（`_publicSiteUrl()`。`PUBLIC_SITE_ORIGINS` の localhost でない最初の値。今は `https://evecre.pages.dev`）。新しい環境変数は足さない
- `publicSiteUrl` が `null` のときはリンクを出さない
- 同じタブで開く

### 1-2. 展示モード：しばらく操作が無ければ外部サイトの Top に戻る

外部サイトは、展示モードのときだけ `/explore?kiosk=1` に移動させる（外部サイト側で対応する）。

- `/explore` 以下（一覧・`?event=<id>`・`/explore/<id>`）で、URL に **`kiosk=1`** があれば展示モードにする
  - `sessionStorage` に保存して、`/explore` の中でページを移っても続ける（キーの例：`evecre:explore-kiosk`。読み書きは try/catch）
  - `kiosk=0` で解除
  - 保存したら、URL から `kiosk` を消してよい（`history.replaceState`。告知モーダルの `?event=` と混ざらないように）
- 展示モードの間、**3分**（`180000` ms）操作が無ければ、`<publicSiteUrl>/?kiosk=1` に `location.replace` で移る
  - 操作とみなすもの：scroll・wheel・touchstart・pointerdown・keydown（外部サイトの `idleReturn.js` と同じ）
  - `publicSiteUrl` が `null` なら戻らない（何もしない）
  - ★**戻り先は `publicSiteUrl` だけ。** URL のパラメータで戻り先を受け取らない（他のサイトに飛ばされる穴になる）
- 展示モードのときは、共有の端末なので：
  - **ログイン・新規登録への導線を出さない**（ヘッダーの「イベクリをはじめる」「アプリに戻る」、コメント欄の「ログインしてコメントする」）。来場者が展示の端末でログインして、そのまま次の人に渡るのを防ぐ
  - コメントは読めるが、入力欄は出さない（ログインしていないときと同じ扱いで、案内の文も出さない）
  - いいねは押せてよい（同じ端末なので匿名 ID は1つ。展示の端末からのいいねは1回分になる。それでよい）
- 1-1 の「イベクリについて」のリンクも、展示モードなら `<publicSiteUrl>/?kiosk=1` にする

## 2. やらないこと

- 外部サイトの自動送り（Top の画面を30秒ごとに進める）を `/explore` に作ること
- 展示モードのための新しい環境変数・サーバーの経路
- `/api/public/*` の変更

## 3. 確かめること

- `/explore`・`/explore?event=<id>`・`/explore/<id>` のヘッダーに「イベクリについて」があり、`https://evecre.pages.dev/` が開く
- `/explore?kiosk=1` → 一覧から `/explore/<id>` に移っても展示モードのまま → 3分触らないと `https://evecre.pages.dev/?kiosk=1` に移る（確かめるときは時間を短くしてよい）
- 触っている間は戻らない。`kiosk=0` で解除される
- 展示モードでは、ログイン・新規登録・コメントの入力欄が出ない。いいねは押せる
- `kiosk` の無い URL では、ふだんどおり（戻らない・ログインの導線がある）
